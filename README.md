Status: In development

#Project Overview

This project aims to design and manufacture a compact, lightweight flight controller for autonomous unmanned aerial vehicles (UAVs) weighing less than 250 g.

Building upon the existing EduCopter project, the project focuses on redesigning the original Raspberry Pi-based flight controller using a Raspberry Pi Compute Module 5 (CM5).

The design will prioritise compact PCB architecture, low mass, power efficiency, ArduPilot compatibility and component sourcing through traceable UK and European supply chains.

#Project Objectives

Design a compact custom PCB integrating the Raspberry Pi CM5.

Integrate essential flight-control sensors and communication units.

Implement power management suitable for lightweight UAV operation.

Configure and test ArduPilot firmware on the custom hardware.

Manufacture and validate a functional flight controller prototype.

Integrate the controller into an autonomous UAV with a total mass below 250g.

Evaluate manufacturability, component availability, performance and design trade offs.

#Technical Focus

Hardware: Raspberry Pi CM5, PCB design, IMU, barometric sensing, GPS, motor control and power regulation.

Software: ArduPilot, Linux, hardware abstraction layers and flight control integration.

Validation: Bench testing, communication verification, mass and power measurements, and UAV flight testing.
